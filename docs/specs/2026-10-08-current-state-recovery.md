# 当前研究状态备份与隔离恢复

关联：[主仓精简F01](../../../thesis-ledger/docs/tasks/2026-10-03-multi-source-remaining-acceptance.md#minimal-release-closeout)、[已验收任务](../archive/tasks/2026-10-08-current-state-recovery.md)。本入口服务于已有研究状态的最小恢复，不增加旧版本组合或异地交付要求。

## 范围和保护

- AC1：只备份精确的`thesis-ledger-dev`开发目标，验证正在运行的PostgreSQL/DSA/Worker及数据卷。PostgreSQL custom/no-owner/no-acl dump、DSA在线SQLite备份/非SQLite数据目录、冻结制品分别保存，Manifest绑定镜像、数据库head、业务状态、载荷大小和SHA-256。
- AC2：备份不停止或修改源消费者、数据库和卷；活动回测、源业务保护摘要变化、备份失败不能生成已完成Manifest。权限为目录0700/文件0600，不导出运行环境凭据；备份按私有业务资料保存。
- AC3：恢复入口先校验Manifest、固定文件名及载荷摘要，拒绝任意路径、符号链接和危险归档条目。只恢复到本次随机命名且带所有权标签的隔离PostgreSQL容器，以及全新宿主临时目录，不操作源数据库或现有数据卷。
- AC4：恢复的数据库head和关键业务摘要、SQLite完整性及冻结任务身份必须一致。代表性冻结任务使用Manifest中的应用镜像、断网容器和恢复后的制品进行生产Runner重放；所有Docker状态变更由本仓维护脚本负责。
- AC5：失败保留原备份，清理仅限本次隔离资源；清理失败显式报告，源状态前后不变。当前正式目标更新仍只走`update.sh`，本入口不部署应用或回退当前环境。

恢复入口可以显式指定全新私有输出目录，成功后保留隔离数据库和恢复后的DSA/冻结制品，供实际取用；默认演练仍自动清理。保留模式生成所有权回执，配套清理入口必须核对固定命名/所有权标签和目录中的同一回执，不能操作源环境或任意已有容器。失败仍清理本次资源，不保留未完成副本。

数据文件和版本镜像是不同依赖。本机恢复使用Manifest绑定且仍可访问的本地镜像；不将本机备份或镜像标签宣称为异地灾备。实际交付版本变化后只补录该版本并重验受影响范围。
