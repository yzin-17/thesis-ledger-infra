# 应用部署接口归属

日期：2026-11-11。状态：现行合同。[已完成任务](../archive/tasks/2026-11-11-application-deployment-interfaces.md)，[验证记录](../archive/evidence/2026-11-11-application-deployment-interfaces.md)。

## 目标与合同

infra 维护本地部署的目标、锁、空间、容器、卷、文件传输、健康等待和失败恢复编排。应用维护构建准备、源码与产物清单、运行兼容条件、载荷应用方式和业务表保护；通过应用 scripts/ 下的显式维护命令供 infra 消费。

- DSA 维护 SDK 构建上下文与缓存、快更载荷和容器内替换脚本、字节码清理、运行快照语义。infra 不重复声明 DSA 的启动命令或源码目录。
- ThesisLedger 维护 Server/workspace 的宿主构建、兼容输入、载荷替换和数据库权限 SQL。快更载荷的目录和文件权限应允许镜像中的非 root Server／Worker 分别遍历和读取，宿主的私有文件掩码不改变这一合同。infra 不列举 workspace 包或业务表。
- 应用语义与测试随所有者迁移；infra 保留正式入口及跨命令的失败恢复测试。AI 业务开关语义测试由主仓消费侧维护，Compose 的配置传递继续由 infra 承载。
- 应用命令不另建部署入口。宿主兼容预检只读；容器内替换仅由持锁的 sync-code.sh 执行。容器创建、重启、回退、健康检查和卷保护仍经正式脚本。

## 验收

- AC1：业务表权限 SQL 与业务开关测试由主仓维护，infra 通过明确路径执行；原断言和保护保持。
- AC2：两个应用的快更准备、兼容判断及容器内替换由应用维护。ThesisLedger 在宿主 `umask 077` 下装配载荷时，Server、Worker 和 workspace 入口及父目录仍符合镜像非 root 用户的读取和遍历权限。路径、符号链接、原生依赖、数据库结构及镜像漂移保护继续生效，修改失败仍回到同镜像。
- AC3：SDK 预取在停机前执行且校验固定版本；infra 仅调用应用构建准备命令，临时构建上下文由应用声明，镜像复用跳过预取。
- AC4：DSA 快照格式兼容已有记录；命令、入口、健康、挂载与端点核验由应用接口维护，infra 继续负责锁、持久化和恢复执行。
- AC5：当前调用者、CI、规则、指南及门禁同步；定向测试后运行仓库脚本检查和只读 Compose 检查。构建编排接口变化后通过正式 update.sh all 完成保留数据更新，核对挂载、数据库结构和健康状态；不能把替身测试描述为真实故障注入。

保留既有未提交改动、业务行为与历史证据。本轮不修改业务数据，不触发外部 Provider、准入或模型调用，不提交或推送。
