日期：2026-11-11。状态：已实施，职责与构建约束持续维护。执行入口：[任务](../archive/tasks/2026-11-11-infra-project-boundaries.md)。

## 目标与所有权

infra 维护本地 Compose、镜像、环境、挂载、健康和必要的更新保护。应用项目维护业务工具、业务验证以及构建定义。完整定位见 [项目规则](../../AGENTS.md#项目定位与职责)。

Provider、数据来源和准入工具归 DSA；研究、AI、账本、回测、Arena、通知及消费侧跨应用验收归 ThesisLedger。脚本的包装、测试和当前说明随职责迁移；已有同名实现核对后分别维护业务实现与宿主入口，避免覆盖。通用备份操作留在 infra，业务保护断言由业务仓提供。

## 行为与兼容

- 保留业务参数、目标校验、有效期、许可、费用和失败语义；受控输入验证不得发起 Provider 或模型实读，不执行准入变更。
- 保留 update.sh、sync-code.sh 以及 all/dsa/thesis-ledger 目标。应用 Dockerfile 接受明确构建参数；SDK 预取在停机前调用 DSA 命令并通过构建上下文提供固定源码。
- infra 不再生成应用 Dockerfile 或检查其具体行；Compose/Bake 指向应用仓库维护的 Dockerfile。依赖、数据库、镜像、互斥和卷保护仍有效。
- 迁移覆盖已跟踪及本地新增的相关脚本；更新当前调用方和说明。归档的历史命令、冻结记录、已有业务数据保持原样。
- 三仓已有未提交修改保留；不清库，不执行 Git 提交或推送。

## 验收合同

- AC1：项目定位与跨仓职责写入项目和工作区规则，迁移清单能追溯旧路径、新路径及责任。
- AC2：业务工具、包装、测试及当前说明由所属项目维护；参数、受控成功与失败路径、保护断言通过，infra 无应用业务实现。
- AC3：应用维护完整构建定义，下载源、基础镜像和 SDK 源通过显式接口配置；Compose/Bake 结构正确，文本变换及对应耦合测试移除。
- AC4：更新与快更、保卷恢复、数据库结构及镜像保护相关定向测试通过；受影响的仓库门禁通过或明确记录无关并发失败。
- AC5：通过正式 update.sh all、DEV_DATABASE_MODE=check 保留数据更新一次；独立核对实际镜像、服务、Worker、结构版本及错误日志，未通过不得结案。
- AC6：当前文档、CI、打包与跨仓路径一致，历史证据可查，最终核对覆盖全部迁移清单及验收缺口。
