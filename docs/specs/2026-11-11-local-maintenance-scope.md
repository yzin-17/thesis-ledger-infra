# 本地维护能力收敛

日期：2026-11-11。状态：现行合同。[已完成任务](../archive/tasks/2026-11-11-local-maintenance-scope.md)，[验证记录](../archive/evidence/2026-11-11-local-maintenance-scope.md)。

## 行为合同

移除 Docker Desktop 引擎恢复命令及历史镜像数量管理。日常更新继续负责构建、结构检查、启动和健康检查；保卷重装、空间实测、缓存清理、未引用镜像清理及快更保持。

镜像清理只依据容器引用、显式完整镜像 ID、空间探针和本轮构建产物判断保护，不按历史数量或创建时间选择回退版本，不生成回退标签。默认清理仅处理无标签镜像和所选应用的未引用开发标签；保卷恢复的 all-unused 模式保留现有保护边界。显式保护使用 BUILD_PROTECTED_IMAGES，DSA 快照入口继续自动保护其恢复镜像。

Docker Desktop 的启动、状态检查和空闲块回收继续维护；本次移除的是故障重启及强制停启入口。引擎不可用时更新明确失败。

## 验收

- AC1：两个维护能力的实现、调用、参数、专属测试及当前指南移除；历史材料保持原记录并可追溯。
- AC2：共享镜像清理的本地 context、互斥、祖先 PID、活动构建、候选重查与无强制删除保护保持；不操作卷。
- AC3：保卷重装、更新失败停止、镜像复用、DSA 快照与快更定向测试通过，CI 和项目规则一致。编排测试通过受控应用入口验证运行形态的传递与拒绝传播，可单独检出 infra 执行。应用的运行形态规则在应用仓独立验证，正式部署仍调用真实应用入口。
- AC4：修改仅影响宿主维护脚本；本轮不重建应用镜像、不停服务、不清理实际镜像或数据卷；只读核对原服务状态及当前镜像身份。
