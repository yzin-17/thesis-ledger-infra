## 目标与边界

infra 使用项目级 Vitest 开发依赖管理测试，由 pnpm 提供统一运行、文件筛选和监听命令。生产部署继续使用现有 Node 编排及 Shell 入口，保持无 npm 生产依赖。保留当前工作区已有改动和历史验收记录。

## 验收标准

- AC1：安装并锁定兼容 Node.js 24 的 Vitest，维护可复现的包清单与锁文件；`pnpm test` 执行测试，`pnpm test <文件>` 可定向运行，`pnpm test:watch` 提供监听。
- AC2：infra 的全部测试直接使用 Vitest；临时目录清理、异步失败、取消、互斥及受控输入断言保持，默认测试数不减少；删除全部 14 个测试 Shell 包装。
- AC3：CI 使用锁定依赖与统一测试命令；规则、指南和当前调用方同步更新，运行时门禁阻止测试 Shell 包装重新引入。历史执行记录保持原命令。
- AC4：定向、全量、只读 Docker 配置测试和仓库门禁通过。此次仅调整测试工具及测试生命周期，不变更应用镜像、数据结构和部署编排，不重复构建镜像或执行部署。

应用仓库的测试框架由应用维护；本轮只同步其直接引用的测试包装，不扩展为跨仓框架迁移。没有 Git 提交、推送、业务外部调用或 Docker 状态变更。
